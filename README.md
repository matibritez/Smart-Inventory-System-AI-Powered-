# Smart Inventory System (AI-Powered) 🚀

Este proyecto es un microservicio inteligente diseñado para la automatización de inventarios y control de stock utilizando tecnologías de vanguardia en **Backend** e **Inteligencia Artificial**.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Python 🐍
* **Framework:** FastAPI (High Performance)
* **IA/Computer Vision:** YOLOv8 & OpenCV
* **Base de Datos:** PostgreSQL
* **Frontend:** React.js

## 🌟 Funcionalidades Principales
- [ ] **Detección en tiempo real:** Clasificación automática de productos mediante cámaras utilizando YOLOv8.
- [ ] **API Asíncrona:** Gestión eficiente de peticiones de stock con FastAPI.
- [ ] **Dashboard Inteligente:** Visualización de inventario y alertas de stock bajo.
